## 🧮 计算逻辑说明

### 1. 基础代谢率 (BMR)

采用 **Mifflin-St Jeor 公式**：

```
BMR = 10 × 体重(kg) + 6.25 × 身高(cm) - 5 × 年龄(岁) + 性别系数
```

- 男性：性别系数 = **+5**
- 女性：性别系数 = **-161**

### 2. 每日总消耗 (TDEE)

```
TDEE = BMR × 活动系数
```

| 活动水平 | 系数 | 说明 |
|---------|------|------|
| 久坐 | 1.2 | 几乎不运动 |
| 轻度活动 | 1.35 | 每周运动 1-3 天 |
| 中度活动 | 1.55 | 每周运动 3-5 天 |
| 高强度活动 | 1.75 | 每周运动 6-7 天 |

### 3. 宏量营养素分配

```
蛋白质(g) = 体重(kg) × 蛋白系数
脂肪(g)   = 体重(kg) × 脂肪系数
碳水热量   = TDEE - (蛋白质×4) - (脂肪×9)
碳水(g)    = 碳水热量 ÷ 4
```

#### 蛋白质系数参考

| 目标 | 系数 |
|------|------|
| 常规备赛 | 2.4 g/kg |
| 赛前冲刺 | 2.9 g/kg |
| 非赛季维持 | 2.2 g/kg |
| 普通人群 | 1.7 g/kg |

#### 脂肪系数参考

| 目标 | 系数 |
|------|------|
| 通用 | 1.0 g/kg |
| 控形态 | 0.8 g/kg |
| 激素偏弱 | 1.2 g/kg |

### 4. 碳水循环方案

**核心原则：蛋白质和脂肪每日固定，仅碳水化合物浮动**

- **两档循环**：高碳日 / 低碳日交替
- **三档循环**：高碳日 / 中碳日 / 低碳日轮转
